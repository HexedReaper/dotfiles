# Hexed Reaper's Dotfiles

> A place where I will share my dotfiles, configs, themes, wallpapers, etc


## How to use

1. clone the repo
```shell
git clone https://github.com/HexedReaper/dotfiles.git
```

2. copy, make symlinks, or move files you need :D

```shell
cp -r ...
cp ...
mv ...
ln -s ...
```


## Wallpapers

1. Clone repo if u haven't done it yet.
```shell
git clone https://github.com/HexedReaper/dotfiles.git
```



3. Enter the cloned directory
```shell
cd dotfiles
```

2. Make symlink with this command

```shell
ln -s ./wallpapers ~/PATH/YOU/WANT
```

> Enjoy!
